# Модуль «Каталог» (лендинг раздела)

## Назначение

Стартовая страница раздела «Каталог»: показывает карточки-ссылки на подразделы,
доступные авторизованному пользователю. Заменяет прежнее поведение, когда
`/catalog` открывал листинг товаров.

## Расположение

```
src/app/pages/catalog/
├── catalog.ts      # CatalogPageComponent — тонкая обёртка над SectionPageComponent
└── catalog.html    # шаблон с <app-section-page />
```

Общая вёрстка и логика — в переиспользуемом компоненте
`src/app/components/section-page/` (см. [section-page.md](../components/section-page.md)).

## Маршрут

| Путь       | Компонент              |
| ---------- | ---------------------- |
| `/catalog` | `CatalogPageComponent` |

Определён в `src/app/app.routes.ts`. Пункт меню «Каталог» приходит из
`ModuleSeeder` на бэкенде (`path = /catalog/`).

## Компонент `CatalogPageComponent`

Селектор `app-catalog-page`, standalone, `OnPush`. Рендерит
`<app-section-page title="Каталог" sectionPath="/catalog/" ... />`.

## Известные ограничения

- Список подразделов не обновляется автоматически при изменении прав — нужна
  перезагрузка страницы.
- Если у пользователя есть доступ к каталогу, но нет ни одного дочернего
  модуля, показывается пустое состояние.
