# Хелпер `PriceHelper`

## Назначение

Форматирование денежных сумм: разделители тысяч, опциональные копейки.

## Расположение

```
src/app/helpers/price.helper.ts
```

## Методы

| Метод                  | Результат для `1234567` | Назначение                       |
| ---------------------- | ----------------------- | -------------------------------- |
| `format(value)`        | `1 234 567`             | С копейками, если они не нулевые |
| `formatInteger(value)` | `1 234 567`             | Округление до целого, без копеек |

Разделитель тысяч — неразрывный пробел (`\u00a0`), чтобы сумма не переносилась
на новую строку. Дробная часть отделяется запятой.

## Поведение

- `null`, `undefined`, `''` → пустая строка;
- строка с пробелами (`'1 234'`) корректно приводится к числу;
- отрицательные значения сохраняют знак: `-2 500`;
- нечисловые значения → пустая строка.

## Примеры

```ts
PriceHelper.format(1234567); // '1 234 567'
PriceHelper.format(1234.5); // '1 234,50'
PriceHelper.formatInteger(1234.5); // '1 235'
PriceHelper.formatInteger(-2500); // '-2 500'
PriceHelper.formatInteger(null); // ''
```

## Использование

```ts
{
    key: 'total_price',
    title: 'Сумма заказа',
    formatter: (row: OrderModel) => PriceHelper.formatInteger(row.total_price),
}
```
